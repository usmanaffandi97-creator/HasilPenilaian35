Tempel (Paste) Tabel Excel Leger Sekelas

Buka file Excel nilai kelas Anda. Blok seluruh tabel dari baris judul (NISN, Nama, Kelas, dan seluruh Mapel), tekan Ctrl + C, lalu klik kotak di bawah dan tekan Ctrl + V.

💡 Format judul bebas: NISN, Nama, Kelas, disusul seluruh kolom nama mapel.

Metode Spreadsheet

Pengisian Lewat Google Sheets (Sheet: Leger_Nilai)

Bapak/Ibu juga dapat langsung membuka Google Spreadsheet, klik sheet Leger_Nilai, lalu paste seluruh tabel nilai sekelas di sana. Setelah selesai, klik menu di atas spreadsheet: 🎓 Menu Nilai SMP → ⚡ Sinkronkan dari Leger_Nilai ke Sistem.

Metode Alternatif: Input Nilai Per Mata Pelajaran
